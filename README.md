# Pyramidal Deformable Convolution

Code and results for *Pyramidal Deformable Convolution: Cross-Scale Feature
Aggregation with Learned Pyramid Depth Offsets* (V. Horbatiuk, V. Sineglazov).

The PDC block extends deformable convolution (DCN) with a learned **depth**
offset along a feature pyramid. For each kernel position it predicts
`(dx, dy, z)`: `dx, dy` shift the sample inside a feature map, and `z` selects
a continuous position among the pyramid levels, read by trilinear
interpolation. With `z` fixed at the reference level the block is an ordinary
DCN.

## Layout

| path | contents |
|---|---|
| `pyrdc/` | the block (`blocks.py`, `sampling.py`), models, data loaders, training loop, losses, metrics |
| `tests/` | unit tests |
| `experiments/run_seg.py`, `run_cls.py`, `run_cityscapes.py` | training runners (segmentation, CIFAR, Cityscapes/ADE20K) |
| `experiments/run_batch_iter*.sh` | the exact commands of every experiment batch, as executed |
| `experiments/KAGGLE.md` | how the Cityscapes and ADE20K runs were executed on Kaggle GPUs |
| `experiments/analyze*.py`, `make_figures.py`, `cost_table.py` | analyses, figures, cost table |
| `results/RESULTS.md` | every reported number, with the statistical test it passes |
| `results/*.csv` | one row per training run |
| `results/per_image/`, `kaggle_artifacts/per_image/` | per-image test metrics of every run (used for the paired tests) |
| `results/logs/`, `kaggle_artifacts/*.log`, `kaggle_artifacts/*.csv` | run logs and per-session result rows |
| `figures/` | the figures, as generated by `experiments/make_figures.py` |

## Setup

```bash
micromamba env create -f environment.yml    # creates the `ml_env` environment
```

The runner scripts call `micromamba run -n ml_env python3 ...`, so keep that
environment name (or edit the scripts). `environment.yml` pins the versions
used for the CPU runs; for GPU training install a CUDA build of the same
PyTorch version.

## Tests

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 micromamba run -n ml_env python3 -m pytest tests/ -q
```

## Reproducing the tables

From the committed CSVs and per-image files, with no training and no GPU:

```bash
micromamba run -n ml_env python3 experiments/analyze.py agg parity seeds cifar
micromamba run -n ml_env python3 experiments/cost_table.py
```

The training-loss analyses (`analyze.py loss`, `loss-sig`, `cityscapes`), the
training-loss figures and the boundary-F1 analysis read TensorBoard logs, and
the depth-usage probes (`analyze_z.py`, `analyze_cifar_difficulty.py`,
`analyze_zstretch.py`) read trained checkpoints. Neither is part of this
repository: place the TensorBoard logs under `tensorboard_logs/` and
`kaggle_artifacts/tb_logs/`, and the checkpoints under `results/ckpts/` and
`kaggle_artifacts/`.

## Re-running the experiments

Datasets are not included. CIFAR-10/100 and Oxford-IIIT Pet are downloaded on
first use. Kvasir-SEG is read from `kvasir_seg_raw/Kvasir-SEG/{images,masks}/`
(the official `kvasir-seg.zip`, extracted; the 800/200 split takes the sorted
file names in order). Cityscapes and ADE20K must be obtained from their
providers and passed with `--root`. Each `experiments/run_batch_iter*.sh`
file lists the commands of one batch; for example

```bash
micromamba run -n ml_env python3 experiments/run_seg.py --help
```

shows every option of the segmentation runner.
